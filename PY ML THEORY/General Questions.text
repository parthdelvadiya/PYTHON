ReLU vs Sigmoid (Activation Functions)
    In neural networks, activation functions decide whether a neuron should be activated or not.
    
    Sigmoid Function
    📌 Definition:
        The Sigmoid function converts any value into a range between 0 and 1.
        𝜎(x)=1/1+(e^-x)
        Good for probability output (like binary classification)
        Output layer for binary classification (e.g., spam detection)
        Output Range = (0, 1)
        SLOW

    ReLU (Rectified Linear Unit)
    📌 Definition:
        ReLU outputs the value directly if positive, otherwise 0.
        𝑓(𝑥)=max(0,𝑥)
        Output Range = [0, ∞)

        Dying ReLU problem (neurons can become permanently 0)
        Works well in deep neural networks
        FAST

Confusion Matrix
    A confusion matrix is a table used to measure how well 
    a classification model is performing by comparing

    |                 | Predicted Positive | Predicted Negative |
    | --------------- | ------------------ | ------------------ |
    | Actual Positive | TP                 | FN                 |
    | Actual Negative | FP                 | TN                 |

    Because it shows where the model is getting confused

    Accuracy
👉 Overall correctness
    Accuracy = TP+TN / FP+FN + TP+TN​

    Precision
👉 Out of predicted positives, how many are correct?
    Precision = TP / FP+TP​

    Recall (Sensitivity)
👉 Out of actual positives, how many did we catch?
    Recall = TP / FN+TP​

    F1 Score
👉 Balance between Precision & Recall
    F1 = 2⋅(Precision * Recall) / Precision + Recall​


Global Interpreter Lock (GIL)

Why is the ReLU activation function generally preferred over Sigmoid in Deep Learning?
    ReLU is preferred over Sigmoid because it trains faster and avoids the vanishing gradient problem.
    
    Sigmoid:
        Output range: (0, 1)
        For very large or very small inputs → gradient becomes almost zero
        
        Uses exponential → slow
            1 / (1 + e^-x)
        
        👉 This causes:
            Slow learning
            Deep networks stop updating weights

    ReLU:
        We define it as:
        𝑓(𝑥)=max(0,𝑥)
        Simple comparison fast process
        
        If 𝑥>0 → gradient = 1 ✅
        
        No shrinking of gradients → faster learning

What is fine tuning?
    Fine-tuning is a technique in machine learning where you take an already trained model 
    and train it a little more on your specific data so it becomes better at your task.

    🔁 Process (Basic Steps)
        1. Load pre-trained model
        2. Give your dataset (input + output pairs)
        3. Train for a few epochs
        4. Save model
        5. Use it for predictions

what is tokenizer?
    A tokenizer is a tool in NLP that converts text into numbers (tokens) so a model can understand it.
    
    "Hello world"
         ↓
    ["Hello", "world"]  (tokens)
         ↓
    [15496, 995]       (token IDs)
