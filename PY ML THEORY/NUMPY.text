Difference Between loc[] and iloc[]

Both are used to select rows and columns from a DataFrame.

The main difference is:

✅ loc[] → label / name based
✅ iloc[] → integer position / index based


import pandas as pd

df = pd.DataFrame({
    "Name": ["Parth", "Rahul", "Aman"],
    "Age": [21, 22, 23],
    "Salary": [50000, 60000, 55000]
})

print(df)

    Name  Age  Salary
0  Parth   21   50000
1  Rahul   22   60000
2   Aman   23   55000

df.loc[row_label, column_name]

print(df.loc[1, "Name"])
Rahul

print(df.loc[:, ["Name", "Salary"]])
    Name  Salary
0  Parth   50000
1  Rahul   60000
2   Aman   55000

🔹 iloc[] → Integer Position Based

df.iloc[row_position, column_position]
print(df.iloc[1])
Name      Rahul
Age          22
Salary    60000
Name: 1, dtype: object

print(df.iloc[1, 0])
Rahul
