What is Pandas?

Pandas is used for:
    data loading
    data cleaning
    preprocessing
    feature engineering
    missing value handling
    analysis

Series → 1D
DataFrame → 2D table

import pandas as pd

df = pd.DataFrame({
    "Name": ["Parth", "Rahul", "Aman"],
    "Age": [21, 22, 23],
    "Salary": [50000, 60000, 55000]
})

print(df)
